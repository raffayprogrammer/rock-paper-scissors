# Ali's Rock-Paper-Scissors Game

## Description
A simple command-line Rock-Paper-Scissors game built with Python. Play against the computer or challenge friends locally.

## Features
- Classic rock-paper-scissors gameplay
- Computer opponent with random moves
- Score tracking
- Clean and intuitive interface

## How to Play
1. Clone this repository
2. Run `python main_py.py` or `python RPS.py`
3. Choose your move: Rock, Paper, or Scissors
4. Watch the computer make its choice
5. See who wins!

## Setup
- Python 3.x required
- No additional dependencies needed

## Files
- `main_py.py` - Main entry point
- `RPS.py` - Game logic implementation
